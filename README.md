# 🎲 Simulador de Loteria em Java

Projeto desenvolvido em Java com o objetivo de simular um sistema simples de loteria, permitindo o cadastro de múltiplos bilhetes e a realização de sorteios automáticos.

---

## 📌 Funcionalidades

- Registro de múltiplos bilhetes
- Escolha de 6 números pelo usuário (entre 1 e 60)
- Geração automática de números aleatórios
- Ordenação dos números sorteados
- Contagem de acertos
- Exibição do resultado final para cada bilhete

---

## 🧠 Conceitos Aplicados

- Programação Orientada a Objetos (POO)
- Encapsulamento
- Arrays
- ArrayList
- Laços de repetição
- Scanner para entrada de dados
- Classe Random para geração de números aleatórios
- Arrays.sort() e Arrays.toString()
